# Microstrip Patch Antenna Design using ANSYS HFSS

## 📌 Overview

This project presents the **design and simulation of a microstrip patch antenna operating at 28 GHz** using **ANSYS HFSS**. The antenna employs an **inset/T-shaped feed technique** to achieve proper impedance matching and is analyzed for key RF performance parameters. The design targets **5G millimeter-wave (mmWave) communication applications**.

---

## 🎯 Objectives

* Design a rectangular microstrip patch antenna for **28 GHz**
* Achieve good impedance matching using inset/T-feed
* Analyze antenna performance parameters such as S11, VSWR, gain, and radiation pattern
* Validate suitability for **5G mmWave systems**

---

## 🛠 Software Tool

* **ANSYS HFSS (High Frequency Structure Simulator)**

---

## 📐 Antenna Specifications

* Antenna Type: Microstrip Patch Antenna
* Operating Frequency: **28 GHz**
* Feed Technique: Inset / T-shaped Feed
* Simulation Domain: HFSS 3D EM Solver

---

## 📊 Simulation Results

### Key Performance Metrics

* **Resonant Frequency:** 28 GHz
* **Return Loss (S11):** −21.56 dB at 28 GHz
* **−10 dB Bandwidth:** 26.84 GHz – 29.60 GHz
* **VSWR:** 1.18 at resonance
* **Peak Gain:** 6.83 dB
* **Input Impedance:** ~42 Ω at 28 GHz

The antenna exhibits **good impedance matching, low VSWR, and stable radiation characteristics**, making it suitable for high-frequency wireless applications.
